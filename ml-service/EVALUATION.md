# ML Evaluation

The training script evaluates a churn classifier with a stratified held-out test set.

## Why these metrics?

Churn data is commonly imbalanced, so accuracy alone is not enough. Recall measures how many actual churners are detected; precision measures how many flagged customers are actually churners; F1 summarizes the precision/recall balance; ROC-AUC measures ranking quality across thresholds.

## Reproducibility

Use:

```bash
python train.py --data data/WA_Fn-UseC_-Telco-Customer-Churn.csv
```

The script uses `random_state=42` and a fixed 80/20 stratified split.

Do not copy metrics from another project or dataset. Publish the numbers generated by your own run.
