## RecallIQ — AI Customer Re-Engagement Platform

**Tech:** JavaScript, Node.js, Express, Python, FastAPI, scikit-learn, MongoDB

- Built a full-stack customer-retention platform that analyzes behavioral signals and produces explainable churn-risk scores through a Python ML service.
- Developed REST APIs for customer, campaign and analytics workflows, with MongoDB-ready persistence and a JSON fallback for local development.
- Implemented risk-based re-engagement recommendations and AI campaign drafts, connecting model output to an interactive customer dashboard.
- Added a reproducible Logistic Regression training/evaluation pipeline with preprocessing, class balancing, train/test evaluation, ROC-AUC, precision, recall, F1 and confusion matrix reporting.
